# tui-pet-agentic 🐉

> **⚠️ PROJECT MIGRATED** — This terminal version has been migrated to a modern web application!

## 🌐 New Web Version

The pet game has been completely reimplemented as a React/TypeScript web application with **significantly enhanced features**:

### ✨ Visit the New Version
**[ReactTS-Portfolio Pet App](https://github.com/esarnb/ReactTS-Portfolio)**

### 🚀 New Features in Web Version

- **11 Pet Types**: Dragon, Penguin, Kitty, Puppy, Turtle, Otter, Walrus, Seal, Baby Bear Cub, Frieren (anime character), Parrot
- **Beautiful SVG Animations**: Mood-based animations (idle, happy, hungry, sad, sleeping)
- **Cloud Sync**: Automatically sync pet progress across devices
- **Multi-Device Support**: Resolve conflicts when playing on phone, laptop, etc.
- **Per-Pet Progress Tracking**: Each pet has independent saves
- **Enhanced UI**: Modern, responsive design with Mantine components
- **Smart Autosave**: Syncs every 60 seconds + on user interaction

### 📋 Original Features (Still Available)

All the original terminal features are preserved:
- ✅ Pet evolution (egg → hatchling → drake → dragon)
- ✅ Mood system (idle, happy, hungry, sad, sleeping)
- ✅ Stat tracking (hunger, happiness, energy, XP)
- ✅ Actions (feed, pet, play, sleep, wake, rename)
- ✅ Cooldown system for actions
- ✅ Age tracking and interactions counter

## 📂 Legacy Code

This repository contains the original Python/Terminal implementation using the `rich` library. It's kept for reference and nostalgic purposes but is no longer actively maintained.

### Running the Terminal Version (Archived)

```bash
# Setup
pip install -r requirements.txt

# Run
python pet.py status
python pet.py feed
python pet.py pet
python pet.py play
python pet.py sleep
python pet.py wake
python pet.py rename [name]
python pet.py evolve
python pet.py reset
```
